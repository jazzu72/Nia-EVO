# Quantum Odyssey Starter Deck

The first physical-digital card prototype.

## Card categories

- Character
- Need
- Want
- Budget
- Goal
- Decision

## Digital connection

Cards can eventually contain QR codes that open:

/money-munchkins/

or specific learning missions.

## Production rule

Prototype digitally first.

Do not order inventory until parent/teacher pilot feedback validates:
- gameplay clarity
- educational value
- card durability
- child engagement
- willingness to recommend
