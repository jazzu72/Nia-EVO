# Money Munchkins Learning System

Every mission contains:

- Age band
- Learning domain
- Skill
- Learning objective
- Game mechanic
- Mastery criteria
- Parent prompt
- Teacher guidance

## Design Principle

Money Munchkins teaches through:

Story
→ Problem
→ Choice
→ Consequence
→ Explanation
→ Practice
→ Reflection
→ Mastery

The game should reward thoughtful reasoning, not simply clicking the correct button.

## Starter Curriculum

MMQ-001 — Money Basics / Decision Making

MMQ-002 — Needs vs. Wants / Classification

MMQ-003 — Budgeting / Allocation
